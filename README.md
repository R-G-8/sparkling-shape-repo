# numbawatchd

Upload your streaming watch history, rank what you've watched, and get
recommendations from your rankings and your friends'. MGT 656 team project
(team `sparkling-shape`).

## Run locally

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # then edit the passwords
set -a; source .env; set +a
python manage.py migrate
python manage.py seed
python manage.py runserver
```

Without `DATABASE_URL`, local development uses SQLite. Staging and production
use Postgres (Neon).

## Tests

```bash
SECRET_KEY=x python manage.py test
```

## Deploy (Render + Neon)

`render.yaml` defines the staging web service. `build.sh` installs, collects
static files, migrates, and seeds on every deploy. Set these in Render:
`DATABASE_URL` (Neon), `GRADER_ADMIN_PASSWORD`, `GRADER_MEMBER_PASSWORD`.
`SECRET_KEY` is generated by Render. The A/B page lists every member's
nickname by default; `TEAM_MEMBER_NICKNAMES` overrides that list if set.
